# CLAUDE.md

This repo ships the **`ui-ux-designer`** Agent Skill.

For any UI/UX design task — designing or auditing an interface, a screen/component spec,
a design system, design tokens, a user flow, a mobile-first layout, or a WCAG/UX review —
use the skill at [`skills/ui-ux-designer/`](skills/ui-ux-designer/): read
[`SKILL.md`](skills/ui-ux-designer/SKILL.md) first, then load a file from `references/`
only when the task touches that domain (progressive disclosure).

It describes and prescribes interfaces and produces an **Interface & Journey Guide**; it
does **not** write code or choose the tech stack. See [`AGENTS.md`](AGENTS.md) for
cross-agent usage and [`README.md`](README.md) for install per platform.
